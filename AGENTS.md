# AI Instructions

## Current state
- Static multilingual marketing site (EN, RU, HE) for maxfullstack.com.
- No build step, framework, or client JavaScript.
- Contact is a static mailto link in each language page.

## Rules for future AI work
1. Keep the repository minimal.
2. Add files only when they are required for the current task.
3. Prefer simple static output unless the task explicitly requires a framework.
4. Do not add unused assets, demo files, placeholder libraries, or duplicate variants.
5. Before creating new files, explain the intended structure in the task output or commit message.

## Maintenance
If the repository grows again, remove anything unused and keep only the files required for the delivered result.
