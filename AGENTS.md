# AI Instructions

This repository was intentionally cleaned and reduced to a single instruction file.

## Current state
- There is no active application code here.
- Treat the repository as an empty starting point.
- Do not assume any previous structure, build system, framework, or assets still exist.

## Rules for future AI work
1. Keep the repository minimal.
2. Add files only when they are required for the current task.
3. Prefer simple static output unless the task explicitly requires a framework.
4. Do not add unused assets, demo files, placeholder libraries, or duplicate variants.
5. Before creating new files, explain the intended structure in the task output or commit message.
6. If a task is exploratory, start by updating this file with a short plan before adding code.

## Suggested baseline for rebuilding
Only create these when needed:
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## Maintenance
If the repository grows again, remove anything unused and keep only the files required for the delivered result.
